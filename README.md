# Cimian Web Studio

A web workspace for Cimian software repositories: browse packages, edit
pkginfo and manifests, review changes, and publish through an explicit workflow.
Inspired by the native [CimianStudio](https://github.com/windowsadmins/cimian-studio) app.

Cimian Web Studio is the Cimian build of
[FleetMate Web Admin](https://github.com/rodchristiansen/fleetmate-web-admin).
The source, plans, and design studies live there; this repository receives
releases. [Munki Web Studio](https://github.com/rodchristiansen/munki-web-studio) is the sibling build for Munki.

**Status: planning. There are no releases yet.**
